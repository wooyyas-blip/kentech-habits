# 켄텍 해비츠 (KENTECH Habits)

켄텍 학생을 위한 가벼운 습관 트래커. 로그인 없이 매일 습관을 체크하고, streak(연속 달성일)와 주간 진행률을 눈으로 확인하며 루틴을 만들어가는 웹 서비스입니다.

## 프로젝트 개요

- "매일 공부하기" 같은 목표는 세우기 쉽지만 지키고 있는지 알기 어렵고, 기록이 보이지 않으면 며칠 만에 동기가 식습니다.
- 켄텍 해비츠는 **추가하고 · 체크하고 · 흐름을 보는** 핵심 동작만 남긴 도구입니다.
- 백엔드/데이터베이스 없이 브라우저 `localStorage`에 데이터를 저장하므로 로그인·비용·설정이 필요 없습니다.

## 주요 기능

- **습관 추가/삭제** — 이름, 이모지 아이콘, 색상 태그 지정
- **일일 체크** — 오늘 완료 버튼 한 번으로 토글, 날짜별로 기록
- **streak 계산** — 연속 달성일 자동 계산 및 🔥 표시
- **주간 진행률** — 이번 주(월~일) 7칸 체인과 진행 바로 시각화
- **통계 대시보드** — 등록 습관 수, 오늘 완료율, 최장 streak, 주간 채움률
- **격려 메시지** — streak 구간 달성 시 응원 메시지 표시

## 페이지 구조

| 경로 | 페이지 | 설명 |
| --- | --- | --- |
| `/` | 오늘 (대시보드) | 습관 목록, 일일 체크, streak·주간 진행률 |
| `/habits/new` | 새 습관 | 이름·아이콘·색상 입력 폼 (클라이언트 검증) |
| `/stats` | 통계 | 요약 카드와 습관별 현황 |
| `/about` | 소개 | 서비스 개념과 사용법 안내 |

## 기술 스택

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS**
- 데이터 저장: 브라우저 **localStorage** (백엔드 없음)
- 배포: **Vercel**

## 로컬에서 실행하기

```bash
# 1) 의존성 설치
npm install

# 2) 개발 서버 실행
npm run dev
```

실행 후 브라우저에서 [http://localhost:3000](http://localhost:3000) 으로 접속합니다.

```bash
# 프로덕션 빌드 확인
npm run build
npm run start
```
